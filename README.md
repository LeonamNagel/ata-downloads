# Ata · transcritor de reuniões

Grave ou envie uma reunião. O Ata separa quem falou, gera a ata e guarda tudo numa pasta por reunião.

## Baixar

Abra a [última versão](https://github.com/LeonamNagel/ata-downloads/releases/latest) e baixe o ZIP do seu computador:

- **Windows:** `Ata-windows.zip`
- **Mac com chip Apple (M1, M2, M3, M4):** `Ata-mac-apple-silicon.zip`
- **Mac Intel:** `Ata-mac-intel.zip`

## Usar

1. Extraia o ZIP e abra `Ata.exe` (Windows) ou `Ata.app` (Mac). No Mac, mova a pasta para fora de Downloads antes de abrir.
2. Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações** e **Executar assim mesmo**. No Mac, clique com o botão direito no app e escolha **Abrir**.
3. Cole a sua chave do [Google AI Studio](https://aistudio.google.com/api-keys) quando o Ata pedir.

O Ata não instala nada. Para atualizar, troque só o programa e mantenha a pasta `Reuniões`. Quando houver versão nova, o próprio Ata avisa no topo da página.

O áudio é enviado ao Google para transcrever. Na faixa gratuita da API, o Google pode usar o material enviado. Peça consentimento das pessoas antes de gravar.
